GNSS signal quality · Rust core · Python API

Know how clean your signal is. Every satellite, every epoch.

geoveil-cn0 reads RINEX 2, 3 and 4 observation files and turns carrier-to-noise density into a 0–100 quality score, per-constellation statistics, CN0 skyplots and interference, jamming and spoofing checks. Give it a broadcast navigation file and it also predicts which satellites should be in view.

QualityBUCU · 1 h · 1 Hz

One number per file, five reasons behind it

The quality score weighs signal strength, availability, continuity, stability and constellation diversity. These are the real components for one hour of 1 Hz data from BUCU, Bucharest.

Rating: A ≥ 90 · B ≥ 80 · C ≥ 70 · D ≥ 60 · F below. CN0 quality is 0 at a mean of 30 dB-Hz and 100 at 45 dB-Hz. Stability is 100 at a CN0 standard deviation of 2 dB-Hz and 0 at 10 dB-Hz.

Threats3 detectors

Three checks for a hostile sky

Each detector watches a different signature. Thresholds are part of AnalysisConfig, so a station on a noisy rooftop and one in an open field can be tuned differently.

Jamming

Sudden, shared CN0 drops

A jammer lowers CN0 on many satellites at once. The flag needs critical CN0 drops in more than 5 % of epochs, together with a low mean CN0 or drops shared across constellations.

jamming_detected
Interference

Sustained degradation

Interference is quieter and more frequent. The flag needs CN0 anomalies, drops beyond the configured thresholds, in more than 1 % of epochs.

interference_detectedinterference_threshold_db
Spoofing

Satellites that should not be there

With a navigation file, the library predicts which satellites are above the horizon. A spoofer replays signals that do not match, so a sustained high share of unexpected satellites raises the flag.

A 24-hour station day in 2.6 seconds

Wall-clock time on public IGS files from 31 December 2025, the same set used for geoveil-mp, on a 2014 server CPU. The analysis runs on one core, so a batch of files scales with the cores you give it. Visibility prediction from broadcast ephemeris is the extra cost of analyze_with_nav.

APIPython 3.9+

A station report in six lines

Install from PyPI, point it at a RINEX file, and read plain Python values back. Wheels for Linux, Windows and macOS.

import hatanaka
from geoveil_cn0 import AnalysisConfig, CN0Analyzer

obs = hatanaka.decompress_on_disk("BOR100POL_R_20253650000_01D_30S_MO.crx.gz")   # geoveil-cn0 reads plain RINEX
nav = hatanaka.decompress_on_disk("BRDC00IGS_R_20253650000_01D_MN.rnx.gz")

analyzer = CN0Analyzer(AnalysisConfig(min_elevation=10.0, time_bin_seconds=60))
result = analyzer.analyze_with_nav(str(obs), str(nav))

q = result.quality_score
print(q.overall, q.rating)                       # composite 0–100 and its letter
print(result.mean_cn0, result.total_satellites)   # 45.1 dB-Hz, 106 satellites for BOR1
print(result.get_constellation_summary("Galileo")["mean_cn0"])
tracks = result.get_skyplot_data()                # azimuth, elevation and CN0 per satellite
